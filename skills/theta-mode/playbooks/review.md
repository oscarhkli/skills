# Review playbook

Use it when drafting review comments on someone else's document or code for the human to approve.

## Drafting findings

Give each finding in three parts, in plain words:

- **Author wrote:** what the line says and means, without its jargon.
- **Ask:** the change you want and why, citing the source that decides it.
- **Comment:** the exact text to post.

The human must be able to judge each finding without opening the file.
